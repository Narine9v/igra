# Зерно веры — «Торжество веры и любви: семейный путь»

Индивидуальная тема WordPress. Сайт не опубликован. Рабочий репозиторий `igra` не влияет на доменное имя.

## Локальный запуск

Требования: Docker Compose, Python 3. Команды из корня репозитория:

```sh
python3 scripts/init-local.py
docker compose up -d --wait
docker compose exec -T wordpress php < scripts/setup-local.php
```

Локальный HTTP-порт — 8080, привязан только к loopback. Настройка выполняется повторно без перезаписи материалов. Локальная учётная запись `local_editor`; случайный пароль хранится внутри локального контейнера в `/var/www/html/.local-admin-password`. Не использовать её для рабочего сайта. Если WordPress уже установлен, скрипт сохраняет существующие учётные записи. Остановка: `docker compose stop`. Не выполнять `down -v`, если нужно сохранить локальные материалы.

Если WordPress создал стандартную запись «Hello world!», удалите её через панель перед публикацией. Скрипт намеренно не удаляет существующие записи.

## Как добавлять новости

В панели WordPress: **Записи → Добавить запись**. Укажите заголовок, основной текст, дату и изображение записи. Сохраните черновик для проверки или опубликуйте. Главная автоматически показывает последние шесть опубликованных записей со ссылками на полный текст. Дата начала работы команды — 01.10.2026; текст и факт получения поддержки нужно подтвердить до публикации. Будущие записи по стандартному механизму WordPress публикуются по расписанию.

## Оформление и материалы

**Внешний вид → Настроить → Свойства сайта**: загрузить исходный официальный логотип центра. **Проект «Семейный путь»**: логотип грантов, время январской встречи, фото опыта, ссылки на запись, прошлые видео и аудио. Пока ссылок записи нет, кнопки открывают сообщение о подготовке регистрации; сбор персональных данных не выполняется.

Исходные логотипы из чата пока не доступны как отдельные локальные файлы: они не перерисованы и не заменены поддельными эмблемами. Их нужно загрузить через панель. Логотип грантов предусмотрен компактным.

Страницы с адресами `foto-i-video` и `partnery` созданы черновиками. Наполните их блоками галереи, видео и логотипов и опубликуйте: содержание отобразится в одноимённых секциях главной. Используйте разрешённые к публикации фотографии. Пока материалы не готовы, отображаются нейтральные заполнители. Не выдавать их за фотографии прошедших событий.

Основное описание и карточки мероприятий находятся в `theme/zerno-very/front-page.php`. Новости, фото и партнёры редактируются без изменения кода. Декоративная иллюстрация с волхвами создана для проекта; декоративные ангелы добавлены отдельными изображениями с прозрачным фоном.

## Перенос на Timeweb

На сервере нужны поддерживаемые WordPress PHP/MySQL, HTTPS и резервные копии. Параметры сервера ещё не получены. Не переносить локальные учётные записи или пароли. Установить актуальный WordPress, загрузить ZIP темы через **Внешний вид → Темы → Добавить → Загрузить тему**, активировать, загрузить логотипы и материалы. Проверить формы, мобильную версию и согласованные новости. Затем подключать домен и открывать индексацию. Docker-конфигурация предназначена для локальной разработки, не является готовой конфигурацией публичного сервера.

Архив темы можно собрать: `python3 scripts/package.py`. Для дальнейшей работы использовать существующий checkout, отдельный worktree не требуется.

## Проверки

PHP: `docker compose exec -T wordpress sh -c 'for file in wp-content/themes/zerno-very/*.php; do php -l "$file" || exit 1; done'`.

Функциональная проверка (только на локальной установке):

```sh
docker compose exec -T wordpress php < tests/content-smoke.php
node tests/browser-smoke.cjs
docker compose exec -T wordpress php < tests/cleanup-smoke.php
```

Для браузерной проверки нужен доступный Node-модуль `playwright` и Chromium (`CHROMIUM_PATH`, по умолчанию `/usr/bin/chromium`). Скрипт делает снимки на ширинах 390, 768 и 1440 и проверяет переход к новости, меню, окно регистрации и отсутствие горизонтальной прокрутки. Удалять тестовую запись нужно и после неуспешной проверки.

## Обновление 1.1.0: команда и волонтёры

Убрано слово «православный» и его формы из текстов темы. Добавлены секция и пункт меню «Команда». Имена и фотографии не выдуманы: до заполнения показаны два информационных блока.

Чтобы заполнить раздел, создайте в WordPress страницу «Команда проекта и волонтёры», добавьте блоками фотографии, имена, роли и описание команды, затем отдельную группу волонтёров. Опубликуйте страницу. В **Внешний вид → Настроить → Проект «Семейный путь» → Страница с командой и волонтёрами** выберите эту страницу и сохраните настройки. Страница с адресом `komanda-proekta` подхватывается автоматически, если другая не выбрана. Черновики и страницы под паролем в секцию не выводятся.

Обновление установленной темы: загрузите свежий `dist/zerno-very.zip` через **Внешний вид → Темы → Добавить → Загрузить тему**, затем выберите замену установленной версии. Название каталога темы сохранено; записи, медиафайлы и настройки в базе данных не удаляются. Перед обновлением рекомендуется резервная копия средствами хостинга. Не удаляйте тему перед загрузкой.

## Обновление 1.2.0: семейная иллюстрация, орнаменты и новость

Первый экран заменён композицией с семьёй на переднем плане и волхвами вдали. Вдоль разделов добавлены золотистые оливковые орнаменты; фон светлый, текст вынесен из иллюстрации для читаемости. Содержание и настройки логотипов сохранены.

После обновления темы откройте **Инструменты → Материалы проекта → Открыть черновик новости**. Будет создана запись «🌟 Готовимся к Рождественским встречам!» с согласованным текстом, контактным телефоном и ссылкой на канал. Повторная кнопка открывает существующую запись без перезаписи правок. Она не публикуется автоматически. Укажите дату онлайн-встречи перед публикацией: дата пока не подтверждена. Добавьте присланный снимок встречи в **Изображение записи**; исходный снимок не генерируется и не перерисовывается. Затем проверьте материал и опубликуйте его в WordPress.

Эти материалы доступны только пользователям с правом редактирования записей; создание защищено штатным nonce WordPress. Локальный браузерный тест инструмента: `node tests/materials-smoke.cjs` (использует локальную тестовую учётную запись и меняет только тестовый черновик).
